# Little Lottery Data Laboratory

Magnum Lucky Number Booklet — a small full-stack app to save
personal favourite numbers for five Magnum game formats.

## Tech Stack
- ReactJS (frontend)
- FastAPI (backend)
- MongoDB (storage)

## Project Structure

├── backend/ # FastAPI + MongoDB
└── frontend/ # ReactJS
